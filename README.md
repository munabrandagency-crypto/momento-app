# Momento Scanner

Scanner de QR codes d'invités pour les mariages Momento Expérience.
Il fonctionne avec ou sans internet, et Google Sheets sert de base de données.

- Site : https://checkin.experiencemomento.com
- Administration : https://checkin.experiencemomento.com/admin.html
- Script central Google Apps Script : `apps-script/Code.gs`
- Installation et utilisation : [GUIDE.md](GUIDE.md)
